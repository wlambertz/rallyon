# UI Kit — Player View

The player's self-service surface (mobile/desktop web). Emphasis on **fairness and
transparency**: where am I, when do I play, what happened.

`index.html`:
- Header with player identity (seed, discipline).
- Metric strip: position, wins, set record, next time.
- **Dein nächstes Spiel** — a dark hero card with the print-block shadow, Doto
  field/time, and navigate/remind actions.
- Tabs: **Meine Spiele** (match history via MatchCard), **Tabelle** (standings with
  the player's row highlighted), **Info** (fair-play notice banner).

Light "paper" theme, centered single-column reading width. Composes Metric, Tabs,
Card, MatchCard, DataTable, Banner, Button. Self-contained; German copy.
