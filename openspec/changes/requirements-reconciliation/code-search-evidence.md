# Code search supporting the issue 183 analysis

On the current working tree, a case-insensitive `rg` over `service/tournamentmgmt/src/main` for `standings`, `leaderboard`, bracket draw combinations, `eligibility`, `invitation`, `prospectus`, age-group combinations, `withdrawal` and score-result combinations returned only the rules module's `package-info.java` description of eligibility and participation rules. `rg --files service/scoring service/playermgmt application/audience` returned no files. This is a targeted English-name search, not proof that equivalent behavior cannot exist under other names.

Separately, `DraftReplacement.kt` rejects nonempty phases, validates roster shapes and treats doubles bracket entries as team IDs; `DraftPersistenceIntegrationTest.kt` exercises persistence of registration windows and rosters. These observations support N1-10, N2-04, N3-02 and the distinction between doubles pairs and league teams. They do not establish publication, self-registration, invitations, age eligibility, operational draws, ranking calculation or federation exchange. The cited tests were inspected, not rerun for this documentation analysis.

Direct inspection of `setup/configuration/internal/ConfigurationServiceImpl.kt` further shows that `publish`, `openRegistration`, `closeRegistration` and `lockConfiguration` explicitly throw `UnsupportedOperationException`. The published method names and status enum therefore must not be treated as implemented lifecycle behavior. This supports the gap assessment for the corresponding publication and registration actions, but does not establish the absence of every conceivable alternative workflow elsewhere.

An additional case-insensitive search of `service/tournamentmgmt/src/main`, `3rd_party/iam` and `openspec/specs` for `ageclass`, `age.class`, `altersklasse`, `dateofbirth`, `birthdate`, `birth.date`, `geburtsdatum` and `dob` returned no matches. This strengthens the N2-01 investigation, but does not prove that no alternative naming or external player system could represent age eligibility.
